#User Stories
1. As a history lover, I want to play an interesting history-related quiz game so that I can exceed my knowledge.
2. As a student, I want short historical facts after each guess so I can learn something new while playing.
3. As a player, I want a timer-based challenge mode so that I can test my quick recall skills.
4. As a user, I want my past scores saved so I can track my progress over time.
5. As a teacher, I want to take historical image quiz for my students so they can use the app as a learning tool.
6. As a player, I want to zoom into parts of the photo so I can examine details that might help me guess.
7. As a new user, I want a short tutorial the first time I play so I understand how the game works. 
8. As a curious player, I want categories (history, inventions, culture, etc) so I can focus on my favorite topics.
