#User Stories
1.	As a history lover, I want to compete on a global leaderboard so that I can compare my knowledge with others worldwide.
2.	As a casual player, I want hints (like decade ranges) so that I don’t get stuck and lose motivation.
3.	As a student, I want short historical facts after each guess so I can learn something new while playing.
4.	As a competitive player, I want a timer-based challenge mode so that I can test my quick recall skills.
5.	As a returning user, I want my past scores saved so I can track my progress over time.
6.	As a teacher, I want to curate a set of historical images for my students so they can use the app as a learning tool.
7.	As a curious player, I want to zoom into parts of the photo so I can examine details that might help me guess.
8.	As a new user, I want a short tutorial the first time I play so I understand how the game works.
9.	As a perfectionist, I want different scoring tiers (perfect, close, wrong) so that near misses still feel rewarding.
10.	As a fan of variety, I want categories (history, inventions, culture, etc) so I can focus on my favorite topics.
