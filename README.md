# Historical Art/Image Guesser

## Description and Purpose of the assignment
Historical Art Guesser is an educational game, designed to expand the knowledge of the player for historical arts and further their historical knowledge with interesting arts throughout from history.
Able to use generative AI to give the description of the historical image after each guess of the image while also reinforcing their knowledge of history fully.

## Current Goal features are:
 - Make a simple user database and login to use.
 - Make a sample of at least 100 historical images(of art, sculpture, or photography) with dates, and location.
 - Make a type selection of what type of game. (Current ones are: Time period, Location).
 - Giving an Estimate of time period.
 - Giving an Estimate of the location. (can use GMapsFX)
 - Adding a GPT or any LLM API code to give descriptions after it, if they want.
