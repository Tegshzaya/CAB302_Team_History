🎨 COLOR PALETTE
================

PRIMARY COLORS:
- Purple-Blue Gradient: #667eea to #764ba2
  * Used for: Buttons, links, accents, root background
  * Psychology: Professional, trustworthy, creative

- Green Gradient: #48bb78 to #38a169
  * Used for: Game buttons, success actions
  * Psychology: Success, growth, positive action

BACKGROUND COLORS:
- Root Background: Linear gradient from #667eea to #764ba2
- Card Background: rgba(255, 255, 255, 0.95) (semi-transparent white)
- Form Fields: #f8f9fa (light gray)

TEXT COLORS:
- Title Text: #2d3748 (dark gray)
- Body Text: #495057 (medium gray)
- Subtitle Text: #6c757d (lighter gray)
- Placeholder Text: #adb5bd (light gray)

BORDER COLORS:
- Default Borders: #e9ecef (light gray)
- Focused Borders: #667eea (purple)
- Hover Borders: #ced4da (medium gray)

SHADOW COLORS:
- Card Shadows: rgba(0,0,0,0.15) (semi-transparent black)
- Button Shadows: rgba(102, 126, 234, 0.3) (purple tint)
- Focus Shadows: rgba(102, 126, 234, 0.2) (purple tint)

🔤 TYPOGRAPHY
==============

FONT FAMILY:
- Primary: Segoe UI (modern, clean)
- Fallback: Arial (universal)
- Generic: sans-serif (clean, readable)
- CSS: -fx-font-family: 'Segoe UI', 'Arial', sans-serif;

FONT SIZES:
- Titles: 28px (large, bold)
- Subtitles: 16px (medium)
- Body Text: 14px (standard)
- Buttons: 14px (standard)
- Form Labels: 14px (standard)

FONT WEIGHTS:
- Titles: 700 (bold)
- Subtitles: 400 (normal)
- Body Text: 500 (medium)
- Buttons: 600 (semi-bold)
- Form Labels: 600 (semi-bold)

✨ SPECIAL EFFECTS
==================

GRADIENTS:
- Root Background: linear-gradient(to bottom right, #667eea 0%, #764ba2 100%)
- Buttons: linear-gradient(to right, #667eea 0%, #764ba2 100%)
- Game Buttons: linear-gradient(to right, #48bb78 0%, #38a169 100%)

SHADOWS:
- Cards: dropshadow(gaussian, rgba(0,0,0,0.15), 20, 0, 0, 8)
- Buttons: dropshadow(gaussian, rgba(102, 126, 234, 0.3), 8, 0, 0, 2)
- Form Fields: dropshadow(gaussian, rgba(102, 126, 234, 0.2), 4, 0, 0, 1)

ANIMATIONS:
- Hover Effects: Scale transforms (1.02x, 1.03x)
- Press Effects: Scale transforms (0.98x)
- Transitions: all 0.2s ease (smooth)
- Fade-in: 0.5s ease-in
- Slide-up: 0.4s ease-out

🎯 CSS CLASSES
===============

TEXT CLASSES:
- .title - Large, bold titles (28px, weight 700)
- .subtitle - Medium descriptive text (16px, weight 400)
- .welcome-text - Welcome message styling (24px, weight 700)

BUTTON CLASSES:
- .button - Standard buttons with purple gradient
- .game-button - Special green game buttons

FORM CLASSES:
- .form-section - Form field containers
- .card - Main container styling

ANIMATION CLASSES:
- .fade-in - Fade-in animation
- .slide-up - Slide-up animation
