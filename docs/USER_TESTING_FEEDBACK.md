# User Testing Feedback

## Testing Overview
- Date: September 16, 2025
- Duration: 2 hours
- Testers: 5 users (ages 18-25, students)
- Games tested: Both Guess by Location and Guess by Year

## What We Tested
We asked 5 users to play both games and give feedback on what they liked and what was confusing.

## User Feedback

## Common Feedback Themes

### Positive Feedback
- Clean, professional interface
- Educational value
- Skip button functionality
- Good feedback system
- User-friendly design

### Areas for Improvement
- Map interface could be clearer
- Text size issues on some screens
- Want more artworks
- Total score display at end
- Save progress feature

## Overall Results
- Average rating: 7.8/10
- All users found the app engaging
- Educational value recognized
- Interface generally well-received
- Some usability improvements needed

## Recommendations
1. Improve map interface clarity
2. Add total score display
3. Increase text size options
4. Add more artworks
5. Consider save progress feature
